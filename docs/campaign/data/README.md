# Campaign data

These JSON files are copies of the authoritative campaign tables. **If prose in `../` disagrees with a file here, the file wins.**
Copied on 2026-10-07 from branch `integration`, commit `b1efd46`, directory `docs/design/reconciled/` (`data/` and `defects.json`). The files are byte-for-byte copies, except `sample-night.json`, which is an extract.
Arena tables (`docs/design/reconciled/data/arena/`: combat, enemies, arena tiers, Water spells, stats) are not copied here; they belong to the gameplay export (`../../gameplay/`).

Labels inside the files: `authored` = designed values, not yet tested in play; `simulated` = generated by the reference replayer.
