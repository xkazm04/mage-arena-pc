# W4 — enemy roster, shared-kernel mages and Tiro Games

Full wave card/design note, 2026-10-02, before implementation. Depends on W3 (`2126f57`). Sources: baseline combat constants, Water CSV/sheet, enemy roster and arena tier tables. Target: an actual playable four-bout Tiro Games and reproducible seeded fight evidence, ready for W7 integration. D4 controls remain unchanged; no director/art changes.

## Authority and scope

`enemies.json` owns each enemy's HP, speed, attacks, family, timings, armor/front block and mage competence/caps. `arena-tiers.json` owns the exact Tiro spawn counts, fractional mage competence, duration bands and payouts. `combat.json` owns resets, resource economy and pacing diagnostics. Water spells stay CSV-derived. Missing attack geometry/recovery, spawn layout and policy choices are explicitly authored in a W4 runtime-data section; baseline values are never silently duplicated or overridden in code. Behavior-string numbers (net root/radius, tongue pull, charge lane/stun, moth drain) are parsed and checked.

Implement all four soldiers and four creatures, though Tiro itself only spawns its specified subset. A roster practice selector exposes the remaining enemies without adding them to Tiro. The seasonal plan removes the Echo and loop references: no Echo or later-tier Games here. Mage opponents use **Water proxy loadouts**, visibly labelled as training proxies, until the other schools arrive in W8; do not falsely claim cross-school combat.

## Combat behavior

- Conscript approaches, commits to a forward lunge, recovers and backs off for its data-described interval. Shieldman advances with a frontal shield; direct bolts/projectiles from the front are blocked, areas and flanks bypass it. Slinger kites within its distance band and releases steel toward a committed aim point. Netter warns a ground circle before applying the data's root; rolls/escape avoid it.
- Hounds allocate only two simultaneous melee engagement slots; extra pack members circle. Their death burst is a delayed, absorbable magic activation that survives the owner's Down state. Mire maw alternates slow magic artillery and a physical pull along a committed line. Thornback warns its lane, charges along it, resists Bolt as authored and self-stuns on a wall collision. Hush moths drift toward held wards and drain mana on contact; no invented HP damage.
- Add delivery tags for shield/area rules. Each activation hits each target once, projectiles sweep their path, telegraphs can be interrupted by staff, encased/Down actors cannot act. Contact/status effects respect immunity where relevant. No attack is chosen using invisible future player inputs. Movement/attacks use the same tick order as the player.
- Mage AI produces the same absolute input frame as mouse/keyboard: it has no direct damage, HP, mana, tier or cooldown authority. Seeded, logged decisions; data-defined reaction delay, aim error, decision cadence and absorb/perfect probabilities. Fractional competence linearly interpolates numeric fields between adjacent rows and respects global caps. Attack/defense decisions use observed threats with a first-seen timestamp; a new threat cannot be answered before the reaction delay. Fog suppresses target acquisition; Mirage redirects aim. Higher competence values choose a tier-aware rotation and can leave/interrupt unblockables; lower ones choose among available lines. Mages can miss, exhaust resources and be interrupted.

## Wave lifecycle and integration boundary

Tiro state owns current wave, active/won/lost/intermission/complete phase, deterministic spawn records and one final result. Clear means player alive and all opposing actors Down; a simultaneous Down is a loss. No healing or clearing projectiles until an explicit intermission advance. Advance clears old effects/actors, heals the data fraction of missing HP, refills mana/stamina, resets the collar and preserves composition. Loss grants missio, ends this Games and cannot continue to the next bout. Payout is the entry for the highest completed wave (not all entries summed); result generation is idempotent. Return gold, renown, waves cleared and final qualification for W7 to apply; this stream does not mutate camp state or award mastery itself.

UI: start Tiro from preparation, show wave/opponents/threat family, clear/loss summary and explicit next-bout/retry controls. Composition cannot change between Tiro bouts. Training and roster practice remain separate and restartable.

## Reproducible gate and census definition

1. `npm --prefix packages/core run build`; `npm --prefix packages/core test`: all prior tests plus roster constants/geometry, attack windups, shield flank/area behavior, two-slot packs, death bursts, net/pull/charge/contact mechanics, AI reaction/cadence/probability caps, fractional competence, no-stat-cheat parity, same-seed hash, fog/decoy behavior, reset/resources, simultaneous Down/loss, idempotent payouts and full four-bout progression.
2. `npm --prefix packages/core run report:w4`: **2,000 seeded fights for each of the four Tiro wave definitions**. A fixed reference controller uses the same input interface and rank-one resources, with its policy/profile stored in runtime data before census. It is a simulated policy, not a proxy for certified owner skill. Opponent policies and authored missing geometry may be calibrated, with intermediate reports and changes recorded; never pad time, force outcomes, refill combat resources, scale HP secretly or feed the target duration to a controller.
3. For each wave report sample count, seed range, replay hash digest, wins/losses/timeouts, duration min/p10/p50/p90/max, win-only durations, perfect rate, damage/resources, and two-second dead-air buckets (no casts, telegraphs, projectiles or damage events). Gate: completed-bout **median** inside that wave's authored target band, timeouts <=1%, zero nonlethal Down before combat's early-death floor, finite/bounded states and deterministic replay of sampled seeds. Tails and outcome rates remain visible; do not claim every seed lies in-band or that win rate certifies balance. Timeout length is a safety bound in runtime data, never a forced victory. Also measure the competence ladder under identical starting stats and input opportunities.
4. `npm --prefix packages/game run build`; `npm --prefix packages/game run smoke:w4`: boot production, compose/start Tiro, drive movement/casting, exercise roster practice and show clear/intermission/loss UI with screenshots in `docs/waves/W4-evidence/`. Scripted completion evidence may use a declared harness-only player controller, never hidden player buffs. Repeat projectile performance after expanded rendering; identify hardware/backend.

If the duration gate remains out-of-band after documented tuning, follow the baseline STOP: keep the branch/build consistent, report the failing wave and a specific cut/rework proposal; do not mark pacing green. Any data retuning must occur in its authoritative file and be logged with before/after evidence. Do not discard losing seeds or retune the band to pass. One W4 commit contains the final status/session log and honest evidence.

## Calibration log

Initial 40 seeds per wave (`report:w4 -- --count 40 --tag initial`): medians 17.62 / 18.60 / 16.37 / 19.68 seconds, all below the authored bands. Zero timeouts/early downs/invalid states; soldiers and creatures were all reference-policy wins, mage bouts had both outcomes. This is evidence of excessive spell throughput relative to authored HP, not permission to pad durations or weaken the reference policy. First candidate: halve Water direct damage and stored Return Tide cap in their CSV authority, preserving enemy HP/attacks, all resources, spell costs/timings, healing and control. Re-run the same seeds and report before selecting final tuning. This retuning necessarily supersedes W3's historical damage snapshots; the W3 report must be rerun for the final data, and integration must consume this CSV rather than a copied baseline.

Subsequent generated calibration reports are retained in `W4-evidence/`: half damage brought soldiers/creatures into band but left duels short; Rain Needle damage 2 made the creature wave too long; intermediate 2.4 and 2.25 improved the trade-off. At 2.15, conscript HP 40→38, slinger 30→28 and mire maw 120→100 gave all four medians in band for 200 seeds. The first full census then found semifinal p50 44.55 s (FAIL), preserved as `census-before-final-adjustment.json`. Rain Needle 2.05, with those HP changes, passed the next full census. Other direct Water damage and Return Tide's storage cap remain halved; healing, mana, cooldowns, cast times, controls, enemy damage, all ranks and the reference policy remain unchanged. These are authored tuning choices supported by simulation, not owner-certified feel.

Final kernel review tightened three semantics before the committed census: encasement silences actions but leaves passive regeneration/HoT active; conscript recovery is separate from its one-second backoff; enemies face their committed attack point during windup. Damage telemetry now counts actual HP removed, excluding overkill, while mitigation and stored damage still use the incoming amount. `census-before-kernel-review.json` preserves the earlier passing sample; the final `census.json` is regenerated for the reviewed kernel. Clear waits for surviving hostile hazards (including hound bursts) to settle, so the last enemy cannot cancel its already-earned attack.

The 500-trial-per-level competence report tests all four data rows with identical stats, although Tiro uses only 1 and 1.5. Higher settings are not a monotonic win-rate guarantee: level 4 overcommits to defense in this matchup and can be weaker than level 3. This is a disclosed W9 tuning issue, not a claim that the full later-tier ladder is balanced. The complete-Games browser fixture uses an explicitly selected winning seed with the unchanged reference controller and real between-bout attrition; it is not an unbiased Games win-rate sample.

## Final gate result

All 47 core tests and both package builds pass. Final 2,000-fight-per-wave census: completed-bout medians 37.5833 / 40.4833 / 46.3667 / 58.1333 s; wins 2000 / 2000 / 1813 / 1332; no timeouts, early Downs, invalid states or sampled replay mismatches. The per-fight in-band proportions are 61.0% / 67.7% / 57.4% / 92.25%, explicitly preserving tails. Machine-generated `W4-evidence/census.json` and raw rows are the evidence, not new tuning authorities.

Water and Games production browser checks pass with no exceptions. Selected seed 1 completes the real four-bout lifecycle in 142.25 simulated seconds with no stat changes/refills outside normal intermissions. Repeated projectile performance measures 60.003 fps and 1.3 ms CPU p95 on this PC's D3D11 backend (100 projectiles, 360 samples). Physical latency and human feel remain unmeasured; owner checks and the integration handoff are in the plan session log and game README.
