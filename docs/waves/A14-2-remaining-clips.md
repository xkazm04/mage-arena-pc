# A14 stage 2: remaining clips and gait audit

Stage 1 is committed as a partial delivery because both image providers stopped.
Priority remains with the 68 missing hit/death/corpse slots. No paid stage-2 call
will bypass these latches or spend ahead of that priority. This stage uses only
existing archived pixels and records the exact next-generation queue.

Audit every existing A10 run loop at enlarged scale (most have six keys). Only reorder or
reselect frames if genuinely opposite leading-leg poses already exist and the
sequence becomes anatomically coherent. Do not mirror just half a body, rotate
upright figures, invent limb motion or call repeated paintings a complete gait.
Where a cheap fix is unavailable, retain the clip and record why it needs a new
alternating-stride source. Missing creature front views require new anatomy.

Produce a separate owner board with the actual exported strips, exact missing legacy
A10 clips after applying A14, prepared priority queue, status row and session
entry. Preserve every stage-1 deliverable byte and all charges/latches. Any safe
local correction must be additive, carry source indices and preserve anchors.
No model can approve the result; actual gait/readability remains owner-review.

## Result

Inspected 18 ne/se loops: fourteen six-key strips, three five-key strips and
one three-key strip. Humanoids lack a usable opposite support phase; mire maw
lacks extended launch/landing, and thornback mixes foot changes with heading
drift. Hush moth already has raised/lowered wing keys. No safe cheap correction
was identified, so all A10 animation remains unchanged. This is a review finding,
not an acceptance or a claim that gait has been fixed.

The exact queue contains 68 missing priority A14 slots and 58 other legacy
slots. The full 84-slot legacy backlog includes 26 hit/death slots overlapping
the A14 priority queue; these numbers must not be summed. Enemy cast is attack
and absorb is brace. Five generated creature views remain missing (hound ne/se,
the other three creatures se); mirrored views depend on those masters.

Zero new calls, charges, clips or corrected gaits. Stage-1 commit `3c4f4a9`
delivery bytes and live usage/provider-history files are preserved. Both provider
latches remain. [Owner board](../../art/review/a14/stage2.html),
