# Bundled type

Cinzel variable and Alegreya Sans Regular are used to build local bitmap atlases
at startup. No third-party font service or browser-default type is used.

Sources retrieved 2026-10-02:
- https://github.com/google/fonts/tree/main/ofl/cinzel
- https://github.com/google/fonts/tree/main/ofl/alegreyasans

Both are SIL Open Font License 1.1; complete upstream notices are retained as
`Cinzel-OFL.txt` and `AlegreyaSans-OFL.txt`. Font binaries are unmodified.
